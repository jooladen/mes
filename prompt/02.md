# MES Phase 2 (현장 실행 & 생산/자재/설비 풀 스펙 확장) 구축 지시서

## 1. Phase 2 핵심 개발 기능 항목 (Functional Requirements)
Phase 1(출하성적서/품질)에서 검증된 아키텍처 위에, 공장 전체를 제어하는 MES 4대 확장 모듈을 구축한다.

1. **[생산 관리] 작업지시(WO) 및 공정 진행(Start/End) 제어 화면:**
   - ERP/상위 시스템 연동 작업지시 수신 및 공정별(Routing) 작업 착수/완료 처리.
   - 공정 상태 Machine(대기 -> 진행 -> 완료 -> 중단) 제어 및 작업자/설비 매핑.
2. **[자재/BOM] 자재 투입(Kitting) 및 실시간 BOM 차감 화면:**
   - 공정 착수 시 BOM 기준 원자재/반제품 소요량 자동 계산 및 Kitting 바코드 스캔 처리.
   - 작업 완료 시 재공(WIP) 및 자재 재고 실시간 차감(Backflushing).
3. **[이력/Lot] Lot Tracking (분할/합병/추적성) 관제 화면:**
   - 원자재 Lot -> 공정 Lot -> 최종 제품 Lot 간의 Parent-Child 계층 구조 관리.
   - RealGrid2 TreeGrid를 활용한 Lot Level별 Top-Down / Bottom-Up 360도 이력 추적.
4. **[설비/효율] 설비 비가동 관리 및 OEE(설비종합효율) 분석 화면:**
   - 비가동 사유 코드(고장, 정비, 자재부족 등) 등록 및 비가동 시간 집계.
   - OEE 계산(가동률 x 성능효율 x 양품률) 시각화 Dashboard.

## 2. Phase 1과의 연동 및 아키텍처 연속성 (Architectural Rules)
1. **Phase 1 데이터 모델과의 완벽한 연결:**
   - Phase 2의 '공정 완료' 시점에 Phase 1의 '품질 Spec Auto Pass/Fail 검사'가 자동으로 트리거되도록 공정 흐름을 바인딩한다.
2. **공통 개발 원칙 유지:**
   - **No JPA, Only MyBatis:** 백엔드는 pure MyBatis 사용.
   - **No DTO, Pure CamelMap:** Request/Response 및 Service 내부 전달 객체는 오직 `CamelMap`으로 처리.
   - **No ResponseEntity:** Controller에서는 pure `CamelMap` / `List<CamelMap>`만 직접 반환.
   - **DB Agnostic (Mock -> SQLite -> Oracle):** Profile 스위칭 기반 구조 유지.

## 3. 백엔드 추가 API 구현 사양 (Spring Boot + MyBatis)
- `POST /api/production/work-order-list` : 작업지시 목록 및 공정 진행 상태 조회
- `POST /api/production/process-start` : 공정 착수(Start) 및 자재 validation
- `POST /api/production/process-end` : 공정 완료(End) 및 실적(Good/Scrap) 저장
- `POST /api/material/bom-deduct` : 실시간 자재 차감 처리
- `POST /api/traceability/lot-tree` : Lot 계층형 이력 데이터 조회 (TreeGrid용)

---

## 4. 프론트엔드 추가 UI 및 RealGrid2 활용 (Vue3 + Quasar)
1. **RealGrid2 TreeGrid 연동 (Lot 추적 화면):**
   - RealGrid2의 TreeView 기능을 활용해 `parentLotId` - `lotId` 관계의 계층 데이터를 펼침/접힘 구조로 시각화.
2. **Quasar 기반 현장 POP/키오스크 터치 UI:**
   - 현장 작업자가 장갑을 끼고도 터치할 수 있는 대형 버튼(`QBtn`), 바코드 Input, 공정 진행 상태 Badge 기반 레이아웃 작성.
3. **RealGrid2 기반 비가동/OEE 피벗 분석:**
   - 설비별 비가동 시간 및 OEE 손실 요인(Loss Tree)을 RealGrid2 Pivot View로 그룹핑 출력.
