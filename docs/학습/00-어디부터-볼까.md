## 10번대 · 남의 코드를 읽는 법

### [10 - 결과물부터 거꾸로 일하는법](10-결과물부터-거꾸로-일하는법.md)
**언제**: 프로젝트에 처음 투입됐을 때 · 뭐부터 봐야 할지 모를 때
**핵심**: 코드를 처음부터 읽지 말고 **최종 출력물(성적서 한 장) 을 쥐고 거꾸로** 걷는다. Day 0~3 계획, 김밥 비유.
**여기만 읽어도**: *"DB 설계서부터 보세요" 가 왜 함정인지* 안다.

### [11 - 현업에게 물어볼 질문표](11-현업에게-물어볼-질문표.md)
**언제**: 현업 미팅 직전
**핵심**: 출력물 칸에 **번호를 매겨** 들고 간다. 16칸 실제 양식 + 빈 양식. 막힐 때 쓰는 만능 질문 3개.
**여기만 읽어도**: *"지금은 어떻게 하고 계세요?"* 한 질문의 위력을 안다.

### [12 - 화면값이 어느 테이블인지 찾기](12-화면값이-어느-테이블인지-찾기.md)
**언제**: *"이 값이 어디서 오지?"* 가 막힐 때
**핵심**: 화면 → 코드 → 테이블 5단계. Network 탭 / 특이값 검색 / SQL 로그.
**여기만 읽어도**: **코드는 What만 알려주고 Why는 사람에게 물어야 한다**는 걸 안다.

### [13 - 역추적 실습기록 (8왕복 → 1왕복)](13-역추적-실습기록-8왕복에서-1왕복.md)
**언제**: 실제로 연습해보고 싶을 때 · 판단 기준을 찾을 때
**핵심**: MES·거래명세서 7문제 실습 기록. **판단 기준 7개**(포장지 / defineProps / await / 전화번호부 / 굳힌 값…), **가공 7종**, VSCode 3종 세트.
**여기만 읽어도**: `MST_` 와 `TRN_` 에 같은 컬럼이 있으면 **박제된 값**이라는 걸 안다.

## 20번대 · 코드를 나누는 원리

### [20 - 왜 나누는가 (안다는 건 묶이는 것)](20-왜-나누는가-안다는건-묶이는것.md)
**언제**: *"왜 이렇게 파일이 많아?"* 가 이해 안 될 때
**핵심**: ⭐ **"안다 = 묶인다"**. 1972년 Parnas, 소프트웨어 위기. *"이 소스는 건드리지 마세요"* 가 왜 생기는가.
**여기만 읽어도**: **레거시는 코드가 낡아서가 아니라 의존이 뒤엉켜서 생긴다**는 걸 안다.

### [21 - 같이 바뀌는 것끼리 모은다](21-같이-바뀌는것끼리-모은다.md) ⭐
**언제**: 나눌지 말지 **판단이 안 설 때**
**핵심**: 은행 창구 / 이사 박스 / 현관 스위치. **크기는 기준이 아니다.** git log 로 커밋 종류를 센다.
**여기만 읽어도**: *"이 둘은 같이 바뀌나, 따로 바뀌나?"* 하나로 판단할 수 있다.

### [22 - 화면에 남는 것 나가는 것](22-화면에-남는것-나가는것.md)
**언제**: 화면에서 로직을 빼는데 **어디까지 뺄지** 모를 때
**핵심**: 로직은 **두 종류**(업무 / 화면). 결정적 테스트 — *"화면 없이 배치로 돌린다면 필요한가?"*
**같이 다룸**: `@update:model-value` 가 `onchange` 자리인 이유 / 오케스트레이션 / *"fetch 직접 하지 마라"* 의 뜻.

### [23 - 파일쪼개기 실습 5단계](23-파일쪼개기-실습-5단계.md)
**언제**: 나누기를 **손으로 해보고 싶을 때**
**핵심**: 한 파일 → 4층까지 **단계별 실습 로드맵**. 매 단계 **지표 5개**를 실측(역추적 왕복 / 테스트 가능 / 교체 범위…).
**연결 소스**: `src/practice/split/`

## 30번대 · 이 MES 프로젝트 이해

### [30 - 이 프로젝트가 뭐하는건가](30-이-프로젝트가-뭐하는건가.md)
**언제**: 이 코드를 **처음 열었을 때**
**핵심**: 출하성적서가 뭔지, 화면 5개가 각각 뭘 하는지. **"이거 고쳐주세요" 요청 시 어느 파일을 여는지** 3단계 분류.

### [31 - 용어사전 (생활예제)](31-용어사전-생활예제.md)
**언제**: Lot, 규격, 판정, LATEST_YN… **말이 안 통할 때**
**핵심**: 용어 30여 개를 생활 예제로. **조용한 실패 4종**.

### [32 - 화면 눌러보기 대본](32-화면-눌러보기-대본.md)
**언제**: 화면을 **직접 써보며** 익히고 싶을 때
**핵심**: 현업 4개 역할이 되어 순서대로 클릭. 단계마다 *"정상이면 이렇게 보임"* + **일부러 틀려보기**.

### [33 - 압축된 상태문장 읽는 법](33-압축된-상태문장-읽는법.md)
**언제**: *"F4 품질피벗 / M4 threshold 95 복원 / carry item 3건"* 같은 **한 줄이 안 읽힐 때**
**핵심**: 압축된 인수인계 문장을 해부하는 법. 냉장고 메모 비유.
