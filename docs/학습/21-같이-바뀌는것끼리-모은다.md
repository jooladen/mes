# ⭐ 같이 바뀌는 것끼리 모은다 — 나누는 기준

> *"바뀌는 이유가 다르면 쪼갠다"* 가 무슨 말인지 감이 안 올 때 읽는다.
> 결론부터: **쪼개는 게 목적이 아니라 모으는 게 목적이다.**

---

# 1. 표 하나로 보기

**요청 3개가 왔다. 각각 어느 파일을 고치나?**

| 요청 | **한 파일일 때** | **나눴을 때** |
|---|---|---|
| *"거래처 하나 추가"* | `AllInOne.vue` ✏️ | `orderSeed.js` ✏️ |
| *"합계에 부가세 10%"* | `AllInOne.vue` ✏️ | `ordersApi.js` ✏️ |
| *"금액 글씨 빨갛게"* | `AllInOne.vue` ✏️ | `OrderPage.vue` ✏️ |

## 👀 왼쪽 칸

```
같은 파일이 3번 다 나온다.
```

**한 파일이 3가지 다른 이유로 바뀐다.**
- 데이터가 바뀌어서
- 계산이 바뀌어서
- 디자인이 바뀌어서

> ## ⭐ 이게 **"바뀌는 이유가 여러 개"** 다.
> ## 한 파일이 여러 이유로 계속 바뀌면 → **나눌 때가 된 것.**

## 오른쪽 칸

`orderSeed.js` 는 **데이터 이유로만** 바뀐다. 부가세를 넣든 색을 바꾸든 **손도 안 댄다.**

# 2. 🟢 생활 예제 셋

## ① 은행 창구

> **"오는 이유가 다르면 창구를 나눈다"**

```
예금 창구  │  대출 창구  │  외환 창구
```

😖 한 창구에서 다 하면 — **대출 상담 30분 동안, 통장 정리하러 온 사람이 뒤에서 기다린다.**

## ② 이사 박스

> **"푸는 방이 다르면 박스를 나눈다"**

```
[부엌 박스]   [옷 박스]   [책 박스]
```

😖 다 섞어 담으면 — **부엌 정리하는데 책이 나온다.** 서재로 갔다가 다시 부엌으로 돌아와야 한다.

⭐ **넣을 땐 섞는 게 빠르다. 풀 때 3배 걸린다.** 이게 "한 파일이 처음엔 편한" 이유다.

## ③ 현관 스위치

> **"누르는 이유가 다르면 스위치를 나눈다"**

스위치 하나로 거실 + 주방 + 화장실이 같이 켜진다면 —

```
화장실 갈 때      →  스위치  →  거실·주방도 켜짐
TV 볼 때          →  스위치  →  화장실도 켜짐
요리할 때         →  스위치  →  다 켜짐
```

**하나를 3가지 이유로 누른다.** 그래서 스위치를 3개로 나눈다.

# 3. ⭐ 더 정확한 표현 — "쪼갠다"가 아니라 "모은다"

> # **"같이 바뀌는 것끼리 모은다"**

```
거래처 추가 · 품목 추가 · 단가 수정   →  같이 바뀜  →  한 파일에 모은다 (orderSeed.js)
부가세 · 할인율 · 합계 규칙          →  같이 바뀜  →  한 파일에 모은다 (ordersApi.js)
색 · 폰트 · 칸 순서                 →  같이 바뀜  →  한 파일에 모은다 (.vue)
```

**모으고 나니 결과적으로 3개가 된 것**이지, 3개로 자른 게 아니다.

> 📌 이걸 **응집도(Cohesion)** 라고 부른다 — *"같이 바뀌는 것이 같이 있는 정도"*

## 왜 "모은다"로 기억해야 하나

| 기억하는 말 | 하게 되는 행동 |
|---|---|
| ❌ "쪼갠다" | **무조건 나눈다** → 과잉 분리 |
| ⭐ "모은다" | *"이것들이 같이 바뀌나?"* 를 **먼저 묻는다** → 안 바뀌면 안 나눔 |

😖 **과잉 분리의 증상**: 화면 1개짜리를 4층으로 쪼개서, 역추적 8왕복짜리를 스스로 만든다.

# 4. 🔍 실무 판단 — git log 를 본다

> **"이 파일, 최근 3개월 동안 몇 가지 이유로 고쳤나?"**

| 커밋 메시지들 | 판정 |
|---|---|
| "거래처 추가", "품목 추가", "단가 수정" | **1가지 이유** → 그대로 둔다 |
| "부가세 추가", "색상 변경", "거래처 추가", "정렬 수정" | 🚨 **4가지** → 나눌 때 |

**커밋 메시지가 여러 종류면 그 파일은 여러 주인을 섬기고 있다.**

```bash
git log --oneline -- src/pages/OrderPage.vue | head -20
```

# 5. 막힐 때 던지는 질문

> ## **"이 둘은 같이 바뀌나, 따로 바뀌나?"**

| 답 | 결론 |
|---|---|
| **같이 바뀐다** | 한 파일에 둔다 |
| **따로 바뀐다** | 다른 파일로 |
| **모르겠다** | ⭐ **그대로 둔다.** 확실해질 때 나눈다 |

📌 세 번째가 중요하다. **"나중에 나누는 것"은 쉽고, "잘못 나눈 것을 되돌리는 것"은 어렵다.**

---

# 6. ⚠️ 크기는 기준이 아니다

```
❌ "파일이 300줄 넘으면 나눈다"        ← 크기는 신호일 뿐
⭐ "같은 파일이 여러 이유로 바뀌면 나눈다"
```

| 상황 | 판단 |
|---|---|
| 500줄인데 **한 가지 이유로만** 바뀜 | ✅ **그대로 둔다** |
| 80줄인데 **세 가지 이유로** 바뀜 | 🚨 **나눈다** |

> 300줄은 *"한번 봐라"* 는 신호지 *"나눠라"* 는 명령이 아니다.

# 7. 한 장 요약

```
   ⭐ 같이 바뀌는 것끼리 모은다

   🏦 은행 창구 : 오는 이유가 다르면 창구를 나눈다
   📦 이사 박스 : 푸는 방이 다르면 박스를 나눈다
   💡 현관 스위치 : 누르는 이유가 다르면 스위치를 나눈다

   판단 : "이 둘은 같이 바뀌나, 따로 바뀌나?"
          모르겠으면 → 그대로 둔다

   확인 : git log 로 커밋 메시지 종류를 센다
   주의 : 크기는 기준이 아니다
```
