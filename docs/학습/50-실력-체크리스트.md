# 4. 🚨 최대 약점 — **판단 전에 묻는 것**

오늘 두 가지 패턴이 섞여 있었다.

```
❌ "이 다음은?"  /  "무슨 말인지 모르겠어"  /  (결과만 붙여넣기)

⭐ "orderTable이 custTable을 쳐다본다"
⭐ "머리 + 몸통 만큼 리턴하는 거네?"
⭐ "컨트롤러 서비스 매퍼 맞지?"
```

**둘의 학습량 차이가 3배다.**

| | 일어나는 일 |
|---|---|
| **묻기만 하면** | 답을 받는다 → **3일이면 흐려진다** |
| **판단을 먼저 말하면** | 맞으면 확신이 굳고, 틀리면 **어디가 틀렸는지 정확히** 알게 됨 |

## 📌 고치는 법 — 습관 하나

> **결과를 붙여넣기 전에 한 줄 붙인다:**
> ### *"~인 것 같은데 맞아?"*

**틀려도 된다. 틀리는 게 더 남는다.**
오늘 5번 문제(박제된 단가)에서 **틀렸기 때문에** 그 개념이 확실히 박혔다.

> 📌 **앨리에게**: 준이 판단 없이 결과만 붙이면 **답하기 전에 한 번 되물을 것** —
> *"먼저 어떻게 보이세요?"* 다만 준이 지쳐 있거나 3번 이상 막혔으면 그냥 답한다.
